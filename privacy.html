Last updated: [DATE]

"Home Assistant Family Hub Calendar Sync" (the "App") is a personal, non-commercial application operated by Amer for private household use.

Data the App accesses

With my authorization, the App accesses Google Calendar data (calendar names and event details such as titles, dates, times, and locations) from the Google account(s) I connect.

How the data is used

Calendar data is used only to display my household's schedule on a dashboard running in my own Home Assistant installation. It is not used for any other purpose.

Storage and sharing

Calendar data is retrieved from Google and held only within my private Home Assistant system. It is not sold, shared with, or transferred to any third party, and it is not used for advertising.

Google API Services User Data Policy

The App's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be revoked at any time at myaccount.google.com/permissions, or by removing the integration from Home Assistant, which deletes the stored authorization.
